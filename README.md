# 📚 共享单词本

一个多人实时共享的单词本网站，任何人打开链接都能看到同一份数据，无需注册登录。

🔗 **在线体验：** https://zth158236-hub.github.io/-shared-vocab/

---

## ✨ 功能一览

### 基础功能
- 无需登录，输入昵称即可使用
- 所有访问者共享同一份单词本，数据实时同步
- 添加单词 / 知识点（支持任意语言）
- 添加分类标签和释义备注
- 编辑 / 删除单词
- 导出为 PDF

### 每张单词卡片包含
- **补充栏**：追加例句、用法、近义词等内容
- **留言板**：提问、互动、评论

### 学习模式
| 模式 | 说明 |
|------|------|
| 🔍 测试模式 | 遮住释义，点击卡片才显示，检验记忆 |
| 🔊 朗读发音 | 点击单词即可 TTS 发音 |
| 🎯 每日一词 | 每天自动推送一个单词，全天保持一致 |
| ⚔️ 挑战模式 | 闪卡 + 拼写双模式，可设置数量，支持键盘操作 |

### 统计面板
实时显示：单词总数 · 补充总数 · 留言总数

---

## ⚔️ 挑战模式详解

- 数量可选：5 / 10 / 20 / 50 / 自定义
- **闪卡模式**：看单词猜释义，← 不认识 / → 认识
- **拼写模式**：手动输入单词，3 次机会，支持容错（差一个字母也算接近）
- 结束后显示得分汇总 + 错题回顾
- 键盘快捷键：`F` / `Space` 翻牌，`←` `→` 评分，`Enter` 下一个，`Esc` 退出

## 🚀 自行部署

1. Fork 本仓库
2. 在 [Firebase 控制台](https://console.firebase.google.com) 创建项目，开启 Realtime Database
3. 将 `index.html` 中的 `firebaseConfig` 替换为你自己的配置
4. 在 Firebase 数据库规则中设置 `.read: true, .write: true`
5. 在仓库 Settings → Pages 中开启 GitHub Pages
